Job market paper · with Alexander Kwon · November 2026 draft

From One LATE to Another

Machine Learning and the External Validity of IV Estimates

Read the paper (PDF) ↗︎

The question

An instrumental variable (IV) study estimates a local average treatment effect (LATE) for one population. We call it the sample. We want to predict the LATE in another population, the target, where we only observe people's characteristics. The prediction error is the prediction minus the true value. Zero means a perfect prediction.

I2SLS
Interacted two-stage least squares, the standard approach. It controls for characteristics with linear terms.
DML
Double/debiased machine learning. It uses machine learning to estimate how characteristics relate to the outcome, the treatment and the instrument, so these relationships do not have to be linear.

Notice that both methods still model the treatment effect as linear in characteristics.

Where the prediction error comes from

We split the prediction error into four terms that add up to the total. The terms can have opposite signs, so they can partly cancel.

Term I · Sample errorThe estimate is already off in the sample itself.
Term II · Slope errorThe estimated slope of the effect is off. Because the target has different characteristics, this error carries into the prediction.
Term III · Curve errorThe true effect is nonlinear, but the model is linear. This matters when the two populations differ.
Term IV · Weighting errorThe weights that tell us who in the target responds to the instrument are estimated with error.

Two simulations

We simulate the data, so we know the true LATE and can measure each method's error.

Simple designPeople differ in one characteristic. We set each relationship ourselves, so we can make it nonlinear on purpose. Each setting is repeated 500 times with 10,000 people.
Card designCalibrated to Card (1995), a classic study of the return to schooling that uses living near a college as the instrument. Each setting is repeated 300 times with 18,000 people.

What DML fixes

Characteristics relate to the outcome, the treatment and the instrument. I2SLS controls for these relationships with linear terms, while DML estimates them flexibly. When they are nonlinear, the linear terms in I2SLS can distort the estimated effect. The error shows up in Term I and, when the target differs from the sample, in Term II. This figure varies the instrument and outcome relationships and the difference between sample and target.

  • This part uses the simple design, where people differ in one characteristic, X.
  • Difference between sample and target is how different the target's mix of X is from the sample's.
  • Spread of X is how much people differ in X.
  • Instrument nonlinearity is how nonlinear the chance of getting the instrument is in X. That chance follows an S-shaped (logistic) curve.
  • Outcome nonlinearity is how nonlinear the direct link from X to the outcome is, apart from the treatment effect. The true effect is the same at both levels.

In this figure the true effect is linear, so Term III is zero.

What DML does not fix

Two sources of error remain for both methods. This part uses the Card design. Pick a tab, change the setting, and watch how each term moves.

  • The treatment effect can be nonlinear in characteristics. Both methods model it as linear, so DML's flexibility does not help with this error.
  • Treatment effect nonlinearity is how nonlinear the true effect is. The average effect is the same at both levels.
  • Compliance weights tell us who in the target responds to the instrument. Both methods use the same estimated weights, so DML's flexibility does not help with this error.
  • Difference between sample and target is how different the target's mix of characteristics is from the sample's.
